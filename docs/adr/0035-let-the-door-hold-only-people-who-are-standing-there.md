# 0035. ⚠ 扉に立っているのは、⚠ いま立っている人だけにする

- 状態: **決定**
- 日付: 2026-09-12
- 対象: ⚠ **[`0028`](0028-push-the-hosts-decision-over-a-waiting-socket-that-may-hibernate.md)
  が書いた「扉に立っている人 = 開いている待機 socket」を、⚠ 実装に合わせる**
- ⚠ **機能は足していない。** ⚠ **実際の状態と 画面を 一致させるだけである**(⚠ Owner 決定 2026-09-12)

## ⚠ 何が起きていたか(⚠ 実機 2026-09-12、⚠ Owner のキャプチャ)

> ⚠ **つながっている状態で、⚠ 「ひで さんがノックしています」と
> ⚠ 「ひで さんとつながりました。」が 両方出ている**

⚠ **`docs/adr/0028` は こう書いている:**

> ⚠ **the people at the door ARE the open waiting sockets** — ⚠ **there is no second copy to drift**

⚠⚠ **実装は そうなっていなかった。** ⚠ **待機 socket が閉じても、⚠ ノックは `waiting` のまま
残り、⚠ ルームが終わるまで 扉に立ち続けた。**

```text
⚠ Guest が ノックする           ノック A(waiting)
⚠ Guest が 読み込み直す          ⚠ A は残る。⚠ socket だけが消える
⚠ Guest が もう一度 ノックする    ノック B
⚠ Host が「入れる」→ B が入る     ⚠ A は まだ 扉に立っている
```

## 決定 — ⚠ 3 つ

⚠ **Owner 判断 2026-09-12。** ⚠ **どれか 1 つでは足りない。**

### ⚠ 1. 読み込み直しても、⚠ 同じノックに戻る

⚠ **待っているノックを 端末が覚える。** ⚠ **ページが作り直されても 同じ id に戻る** —
⚠ **so 増えない。** ⚠ **決まった時点で捨てる。**

### ⚠ 2. 誰も見ていないノックは、⚠ 30 秒で 扉から降りる

⚠ **待機 socket が閉じてから `KNOCK_GRACE_MS` 経ったノックを落とし、⚠ Host に `knock-gone`
を送る。** ⚠ **断ったのではない** — ⚠ **誰も決めていない。** ⚠ **so 何も言わずに 降ろす。**

⚠ **鼓動に乗せる。** ⚠ **新しい timer を 1 つも足していない** — ⚠ **Node にも Durable Object
にも、⚠ 同じ 1 本の心拍が すでにある**(`src/signaling/session.ts`)。
⚠ **Host が居ないときは鳴らないが、⚠ 伝える相手も そのときは居ない。**

⚠⚠ **30 秒は 測った値ではない。** ⚠ **待機側の retry は最大 8 秒**(`src/client/guest.ts`)、
⚠ **そこに余白を置いた 選んだ値である**
([`../../.claude/rules/evidence.md`](../../.claude/rules/evidence.md))。

### ⚠⚠ 3. 降ろされた人が、⚠ 黙って永久に待たない

⚠ **サーバが落としたノックを watch し続けると、⚠ 何も来ないまま 待ち続けることになる。**

⚠⚠ **サーバに「そのノックは知らない」と言わせない。**
⚠ **`.claude/rules/security.md` § 3: ⚠ 存在しない部屋のノックと、⚠ Host が応じていない
ノックは 外から区別できてはならない。** ⚠ **「知らない」と早く答えると、⚠ 存在しない部屋だけが
早く答えることになり、⚠ 部屋の有無が漏れる。**

⚠ **so Guest が 自分の断絶時間を 自分で測る。** ⚠ **`KNOCK_GRACE_MS` を越えて socket を失って
いたら、⚠ 戻った時点で 新しいノックから やり直す。** ⚠ **両端が 同じ定数を見る**
(`src/signaling/protocol.ts`)。

⚠ **人は待っているだけである。** ⚠ **叩き直したことは 画面に出さない** — ⚠ **出す意味が無い。**

## ⚠ もう 1 つ — ⚠ 「相手が来た」を言う

⚠ **Owner 決定 2026-09-12。** ⚠ **実際の状態と 表示を 一致させるための、⚠ 最小の protocol 変更。**

⚠ **`peer-left` はあった。** ⚠⚠ **その裏返しが 無かった** — ⚠ **so Host が戻っても、⚠ Guest の
画面は「相手の接続が切れました」のまま 残り続けた**(⚠ 実機 2026-09-12)。

```text
peer-left   ⚠ 相手の socket が 消えた        ⚠ もとから在る
peer-here   ⚠ 誰かが 部屋に来た              ⚠⚠ 足した
```

⚠ **中身は無い。** ⚠ **誰が来たかは言わない** — ⚠ **名前は 本人が `hello` で名乗るものであり、
⚠ Host には そもそも名前が無い。**
⚠ **Host 側は `hello` で 同じことをしていた。** ⚠ **Guest 側には その合図が 無かっただけである。**

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| ⚠ **読み込み直しの重複だけ止める** | ⚠ **タブを閉じた人のノックが 残り続ける。** ⚠ **Owner 判断: ⚠ 両方やる** |
| ⚠ **socket が閉じた瞬間に 降ろす** | ⚠⚠ **待機側は 再接続の途中でも 一時的に消える**(⚠ 最大 8 秒)。⚠ **戻ろうとしている人が 扉から消える** |
| ⚠⚠ **サーバが「そのノックは知らない」と答える** | ⚠⚠ **存在しない部屋のノックだけが 早く答えることになり、⚠ 部屋の有無が漏れる**(`security.md` § 3) |
| ⚠ **降ろすための timer を 新しく足す** | ⚠ **心拍が すでに両方の土台で動いている。** ⚠ **2 つめの時計は 2 つめのずれ方を作る** |
| ⚠ **`peer-here` に 名前を載せる** | ⚠ **名前は 本人が名乗るものである**(`hello`)。⚠ **Host には 名前が無い** |
| ⚠ **叩き直したことを 画面に出す** | ⚠ **人は待っているだけであり、⚠ 何も変わっていない。** ⚠ **新しい文言は 増やさない** |

## ⚠ 越えてはならない境界

```text
⚠ 扉に立っているのは いま立っている人だけ      ⚠ adr/0028 が先に書いている
⚠ 降ろすことを 断ったことにしない              ⚠ 誰も決めていない
⚠ 「知らない」を サーバに言わせない            ⚠ 部屋の有無が漏れる
⚠ 30 秒は 選んだ値                            ⚠ 測った値ではない
⚠ peer-here は 中身を持たない                  ⚠ 誰が来たかは言わない
⚠ 扉のことは Host にしか渡らない               ⚠ adr/0018
```

## ⚠ しないと決めた主張

- ⚠ **「もう扉に幽霊は出ない」とは言わない。** ⚠ **`pagehide` が鳴らずに端末が落ちた場合、
  ⚠ 去った時刻が残らない** — ⚠ **そのときは 叩き直す側に倒れる(⚠ 安全な側)が、⚠ それは
  ⚠ 測ったことではない。**
- ⚠ **30 秒が ちょうどよいとは言わない。** ⚠ **実機で 一度も見ていない。**

  ⚠ **どちらも 中身は 最小である。**
