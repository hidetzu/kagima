# 0012. 診断はアドレス種別だけを言い、それ以上は言わない

- 状態: **決定**
- 日付: 2026-09-05
- 決めた人: **Owner**

## 文脈

⚠ **実測で、両端そろった観測が `selected pair: host/host over udp` を出した**
([`../FIELD-TEST.md`](../FIELD-TEST.md))。
⚠ **スマホの Wi-Fi はオフだった。**

⚠ **ここで `host/host` は 2 つの正反対を意味しうる:**

| 前提 | ⚠ `host/host` が意味すること |
|---|---|
| **IPv4** | ⚠ **両端が同じネットワークにいた。** ⚠ 別ネットワークの試験になっていない |
| **IPv6** | ⚠ **両端がグローバルアドレスを持っていた。** ⚠ **越えるべき NAT が無かった** |

⚠ **1 つのラベルから 2 つの正反対の結論が出る。**
⚠ **so この計器は、⚠ [kagima#16](https://github.com/hidetzu/kagima/issues/16) の観測を解釈できない。**
⚠ **解釈できない観測は、⚠ 観測ではない。**

## 決定

⚠ **診断は、⚠ candidate ごとに `v4` / `v6` / `?` のいずれか 1 語を出す。**
⚠ **アドレスそのものは、⚠ 保持も出力もログもしない。**

⚠ **見てよいのは `familyOf` 1 箇所だけであり、⚠ 返り値はその 3 語しかない。**

## ⚠ 壁の形が変わった。弱くなってはいない

```text
前   ⚠ 「address という語がソースに出てこない」
今   ⚠ 「address を読むのは 1 関数だけ」
   + ⚠ 「その関数は 3 語しか返せない」
   + ⚠ 「レポートに住所が出ない」(⚠ 前からある。⚠ 変えていない)
```

⚠ **狭い例外は、⚠ 切り出して残りを検査することで狭いままになる。**
⚠ **`test/diagnostics.test.ts` は `familyOf` の定義と呼び出しを削り、⚠ 残りに `address` が
1 つも無いことを確かめる。** ⚠ **`.address` の直接読み出しは、⚠ どこであれ禁止である。**

⚠ **変異検査で 3 通りとも落ちることを確認した:**

| 変異 | ⚠ 落ち方 |
|---|---|
| `familyOf` がアドレスをそのまま返す | ⚠ `familyOf leaked something from …` |
| 収集器が `familyOf` を通さない | ⚠ `the collector names an address outside familyOf` |
| レポートが語彙を通さず出す | ⚠ `an address reached the report` |

## ⚠ `?` は失敗ではない

⚠ **mDNS の `.local` candidate は種別を隠す。** ⚠ **そのときは `?` と言う。**
⚠ **推測しない**([`../../.claude/rules/evidence.md`](../../.claude/rules/evidence.md))。

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| **何も出さず、Owner が `webrtc-internals` で毎回確認する** | ⚠ **計器だけでは観測を解釈できない状態が続く。** ⚠ **そして `webrtc-internals` には生アドレスが全部出る** |
| ⚠ **種別ではなく「NAT を越えたか」を出す** | ⚠ **判断をこちらが埋め込むことになる。** ⚠ **後から検証できない。** ⚠ **観測と推論を分ける原則に反する**(`CLAUDE.md` § 7) |
| **アドレスを出し、貼るときに人が消す** | ⚠ **人が消し忘れる。** ⚠ **貼れるように作る、が計器の要件だった** |
| **prefix だけ出す**(`2400:4050::/32` など) | ⚠ **prefix は回線を特定しうる。** ⚠ **1 ビットで足りるものに、それ以上を出す理由が無い** |

## ⚠ しないと決めた主張

- ⚠ **「IPv6 なら TURN は要らない」とは言わない。**
  ⚠ **言えるのは「その経路には越えるべき NAT が無かった」までである。**
  ⚠ **IPv4 しか無い経路については、⚠ 相変わらず何も測っていない。**
- ⚠ **`?` を「IPv4 だろう」と読み替えない。**

## 影響

- ⚠ **`docs/FIELD-TEST.md` の判定表を直した。** ⚠ **`host/host` = 同じネットワーク、は誤りだった。**
- ⚠ **レポートは `host/host over udp v6` の形になり、⚠ v6 の host 同士のときは
  「越えるべき NAT が無かった」と言葉でも言う** — ⚠ **同じ誤読が二度起きないように。**
