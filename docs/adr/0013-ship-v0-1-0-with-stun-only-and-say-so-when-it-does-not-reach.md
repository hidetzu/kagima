# 0013. v0.1.0 は STUN のみで出し、届かなかったときはそう言う

- 状態: **決定**
- 日付: 2026-09-05
- 決めた人: **Owner**
- 置き換えるもの: [`0001`](0001-keep-media-peer-to-peer-and-off-our-servers.md) が保留にした TURN の判断

## 決定

⚠ **v0.1.0 に TURN を入れない。** ⚠ **STUN のみで出す。**
⚠ **繋がらないネットワークの組み合わせが存在することを受け入れる。**
⚠ **そのとき、利用者に「接続できなかった」と伝え、次に何をすればよいかを示す。**

## ⚠ これは測定にもとづく決定ではない

⚠ **`0001` は「実測してから決める」としていた。** ⚠ **実測は 1 経路しかできていない。**
⚠ **so これはスコープの決定であって、⚠ 「STUN で足りる」という測定結果ではない。**

⚠ **測れたもの:** ⚠ 両端が IPv6 の host candidate で直接つながり、⚠ 両端でフレームが流れ、
⚠ 60 秒以上続いた 1 回([kagima#16](https://github.com/hidetzu/kagima/issues/16) のコメント)。

⚠ **測れなかったもの:** ⚠ **IPv4 しか無い経路。** ⚠ **一度も測っていない。**
⚠ **そしてそれが、この issue が本当に問うていたものである。**

## ⚠ 主張しないこと

- ⚠ **「STUN だけで足りる」とは言わない。**
- ⚠ **「TURN は不要である」とも言わない。** ⚠ **入れないと決めただけである。**
- ⚠ **「ほとんどの人は繋がる」とも言わない。** ⚠ **割合は測っていない。**
  ⚠ **他所の公開値は [`../DISCOVERY.md`](../DISCOVERY.md) にあるが、⚠ それは kagima についての
  測定ではない**([`../../.claude/rules/evidence.md`](../../.claude/rules/evidence.md))。
- ⚠ **理論上問題ない、とも言わない。** ⚠ **理論はむしろ逆を言う** — ⚠ **両端が symmetric NAT の
  とき、⚠ STUN だけでは原理的に経路が作れない。** ⚠ **それが起きる頻度を測っていないだけである。**

## なぜ入れないのか

| 理由 | ⚠ 誰の判断か |
|---|---|
| ⚠ **継続的な running cost が発生する** | ⚠ **Owner**([`../PRODUCT.md`](../PRODUCT.md) § 6) |
| ⚠ **メディアを第三者に中継させることになる** | ⚠ **Owner。** ⚠ **約束に触れる**([`0001`](0001-keep-media-peer-to-peer-and-off-our-servers.md)) |
| ⚠ **v0.1.0 の目的は、⚠ 概念が成立するかを確かめることである** | ⚠ `PRODUCT.md` § 2 |

⚠ **relay が不可避になったときに何を守るかは [`0001`](0001-keep-media-peer-to-peer-and-off-our-servers.md)
が既に書いている** — ⚠ **中継はしても復号はしない、⚠ どの hop で誰が何を見えるかを ADR に書く。**
⚠ **その条件は変わっていない。** ⚠ **今回はその手前で止めただけである。**

## ⚠ 受け入れたことの代金は、黙らないことである

⚠ **「繋がらない人が出る」を受け入れる決定と、⚠ 「繋がらないと伝えない」実装は、
⚠ 同時には成立しない。**

⚠ **決定前の実装は `connectionState === "failed"` を誰も見ておらず、
⚠ 画面は「つないでいます。」のまま永久に変わらなかった。**
⚠ **`CLAUDE.md` § 4-1 が名指しで禁じている形である** — ⚠ **進行形は、いま何かが起きているように
読め、⚠ 待てば繋がると思って待ち続けることになる。**

⚠ **so この決定は、文言の実装とひとつづきである。** ⚠ **片方だけを取ることはできない。**

```text
never connected   ⚠ 接続できませんでした。別のネットワークに切り替えて、もう一度お試しください。
had connected     ⚠ 接続が途切れました。もう一度お試しください。
```

⚠ **原因は名指さない。** ⚠ **見えないからである**([`0012`](0012-let-the-diagnostics-say-the-address-family-and-nothing-more.md)
で計器から同じ推測を外した)。⚠ **画面は、計器よりも信じられる場所である。**

### ⚠ この文言について検証できていないこと

⚠ **ブラウザ層は NOT-VERIFIED である。**
⚠ **実ブラウザで ICE を確実に失敗させる検査を書けなかった** — ⚠ **`iceTransportPolicy: "relay"`
で試したが、⚠ ページが先に別の理由で失敗し、⚠ 決定的にならなかった。**
⚠ **通ったふりをするより、⚠ 入れないことにした。**
⚠ **fast tier が、⚠ 文言そのものと、⚠ 両ページの配線の両方を押さえている。**

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| **TURN を入れる** | ⚠ **running cost と、⚠ メディアを第三者に通す判断。** ⚠ **v0.1.0 が答えるべき問いではない** |
| ⚠ **「理論上問題ない」として閉じる** | ⚠ **理論は逆を言う。** ⚠ **測っていない主張を記録に入れることになる** |
| **IPv4-only の実測が済むまで開けておく** | ⚠ **v0.1.0 が 1 つの未測定に止まる。** ⚠ **測定は後からでもでき、⚠ そのとき ADR を足せばよい** |
| **繋がらなかったとき黙っている** | ⚠ **待てば繋がると思って待ち続けることになる**(`CLAUDE.md` § 4-1) |
| ⚠ **文言で原因を推測して見せる** | ⚠ **見えない。** ⚠ **間違った原因は、⚠ 壊れていないものを直しに行かせる** |

## ⚠ いつ見直すか

- ⚠ **IPv4 のみの経路で 1 回でも測れたとき。** ⚠ **手順は [`../FIELD-TEST.md`](../FIELD-TEST.md)。**
- ⚠ **「繋がらなかった」という報告が実際に届いたとき。**
- ⚠ **どちらも「TURN を入れる」を意味しない。** ⚠ **そのときに改めて決める。**

⚠ **この決定を「STUN で足りることが分かった」と要約しないこと。**
⚠ **要約された瞬間に、⚠ 測っていないものが測ったことになる。**
