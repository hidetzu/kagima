# 0030. ⚠ ルームを作る人は Google で名乗る。⚠ 入る人は名乗らない

- 状態: **決定**
- 日付: 2026-09-08
- 対象: ⚠ [`0024`](0024-put-a-temporary-gate-in-front-of-making-a-room.md) の一時的な門を
  **置き換える**。⚠ **[`../PRODUCT.md`](../PRODUCT.md) § 4 と § 5 の行を 1 本ずつ動かす**
  (⚠ Owner 判断、⚠ 同 § 6)

## 文脈

⚠ **[`0024`](0024-put-a-temporary-gate-in-front-of-making-a-room.md) が置いた門は Basic 認証で、
⚠ `user:secret` を 1 つ、⚠ 使う人に配って回る形である。**

```text
⚠ 誰が作ったかは 分からない
⚠ 1 人に渡すと 全員に渡る
⚠ 取り消すには 全員ぶん 変える
```

⚠⚠ **Owner の言葉(2026-09-08): ⚠ 「今の Basic 認証では、サービス化は無理だから」。**

⚠ **これは「あったほうがよさそう」ではない。** ⚠ **門が果たせていない役目が名指しされている**
([`../PRODUCT.md`](../PRODUCT.md) § 4: ⚠ **必要そうだから足す、はしない**)。

## 決定

⚠ **ルームを作る人は Google でサインインする。** ⚠⚠ **入る人は、⚠ 何も変わらない。**

```text
⚠ 作る人   Google でサインイン → 署名した cookie → ルームを作れる
⚠⚠ 入る人  ⚠ URL を開き、⚠ 名前を名乗り、⚠ Host が入れると決める   ⚠ 1 文字も動かない
```

⚠ **境界は 1 本である: ⚠ 作る人は名乗る、⚠ 入る人は名乗らない。**

### ⚠ 段階を分ける

| | ⚠ 誰が作れるか | ⚠ 何が要るか |
|---|---|---|
| ⚠ **段階 1(いま作る)** | ⚠ **許可した人だけ。** ⚠ 許可リストは secret に置く | ⚠ **保存するものは 何も無い** |
| ⚠ **段階 2(あとで)** | ⚠ **Google アカウントを持つ人なら誰でも** | ⚠ **D1**(⚠ 誰が居るかを持つため) |

⚠⚠ **段階 1 では サーバは利用者を 1 行も持たない。** ⚠ **署名した cookie が端末にあるだけである。**
⚠ **so [`0005`](0005-keep-room-state-in-process-memory-only.md) も
[`0023`](0023-write-the-minimum-so-a-room-outlives-its-sockets.md) も動かない。**

⚠⚠ **段階 2 に進む前に決まっていなければならないこと:**
⚠ **[`0022`](0022-start-on-cloudflares-free-tier-with-one-durable-object-per-room.md) の上限は
28.21 room-hours/day であり、⚠ 誰でも作れるなら 他人に使い切られうる。**
⚠ **「誰でも作れる」と「Free のまま」は 同時には成り立たないかもしれない** — ⚠ **そのとき何を
選ぶかは Owner 判断である**([`../PRODUCT.md`](../PRODUCT.md) § 6: ⚠ **ランニングコスト**)。
⚠ **段階 2 は 別の ADR になる。**

## ⚠ 記事どおりには作らない

⚠ **出発点は 公開記事である**(⚠ Cloudflare Workers + Hono + D1 + Google OAuth PKCE + JWT)。
⚠ **そのうち 3 つを 落とす。**

| 記事 | kagima | ⚠ 理由 |
|---|---|---|
| **Hono** | ⚠ **使わない** | ⚠ **`src/server.ts` の `handle` が既にルータである。** ⚠ `CLAUDE.md` § 3: ⚠ **1 プロセスに必要以上のサーバフレームワーク** |
| **JWT ライブラリ** | ⚠ **使わない** | ⚠⚠ **`src/token/join-token.ts` が 同じ形の署名を既に持っている** — ⚠ HMAC-SHA256、⚠ payload の先頭に purpose、⚠ 定数時間比較。⚠ **同じ問いに 2 つの実装を置かない**(`CLAUDE.md` § 3) |
| **D1** | ⚠ **段階 1 では使わない** | ⚠ **許可リストは secret に置ける。** ⚠ **保存するものが無ければ、⚠ 踏む線が 1 本減る** |

⚠⚠ **so 踏む線は 1 本だけになる:**

```text
⚠ a dependency that reaches the network at runtime   → ⚠ Google(認可と JWKS)
```

⚠ **これは避けられない。** ⚠ **Google で名乗る以上、⚠ Google に訊きに行く。**
⚠ **どこで訊きに行くかは 1 か所に閉じる** — ⚠ **サインインの往復だけであり、⚠ 通話にも扉にも
入らない。** ⚠ **Google が落ちていても、⚠ 既にあるルームは動き続ける。**

### ⚠ cookie は join token として通ってはならない

⚠ **同じ秘密で署名するので、⚠ 何も分けなければ 一方が他方として通りうる。**
⚠ **[`0029`](0029-let-a-guest-come-back-with-a-mark-that-works-on-one-room.md) で 1 度 踏んでいる** —
⚠ **あのときはフィールド数が偶然分けていて、⚠ purpose の検査を外しても何も落ちなかった。**

⚠ **so 形を揃え、⚠ purpose で分ける。** ⚠ **そして 両方向で検査する。**

## ⚠⚠ 何を弱めるか

⚠ **[`../PRODUCT.md`](../PRODUCT.md) § 5 はこう書いていた:**

> ⚠ **アカウントを作らせない。** ⚠ **だから、利用者を継続的に識別する手段を持たない。**

⚠⚠ **作る人については、⚠ この約束を kagima はもうしない。**

⚠ **動かないもの:**

```text
⚠ 入る人にアカウントを作らせない        ⚠ 動かない
⚠ 入る人を継続的に識別しない            ⚠ 動かない
⚠ 誰がノックしたかを記録に残さない      ⚠ 動かない
⚠ 録画しない、⚠ 文字起こししない          ⚠ 動かない
⚠ メディアは我々のサーバに来ない        ⚠ 動かない
⚠ 入れなかった人に部屋の有無を教えない  ⚠ 動かない
⚠ Host が居るときに Host が決める        ⚠ 動かない(0017)
```

⚠ **弱めたことは 書いてある。** ⚠ **黙って狭めない。**

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| ⚠ **入る人にもサインインさせる** | ⚠⚠ **それは劣化した kagima ではなく、⚠ 別の製品である**(`CLAUDE.md` § 1)。⚠ **§ 5 の中心が消える** |
| ⚠ **Basic 認証のまま続ける** | ⚠ **配って回る鍵は、⚠ 誰が作ったかを言えず、⚠ 1 人ぶんだけ取り消せない** |
| ⚠ **段階 1 から D1 を入れる** | ⚠ **要らないものを先に入れることになる。** ⚠ **`0022` は「実測が上限に近づくまで先回りしない」と書いており、⚠ ここも同じ形である** |
| ⚠ **記事どおり Hono を入れる** | ⚠ **ルータは既にある。** ⚠ **2 つ目を置くと、⚠ どちらが答えるかが 2 か所に分かれる** |
| ⚠ **JWT ライブラリを入れる** | ⚠ **署名は既にある。** ⚠ **`0029` が purpose の分離まで作ってある** |

## ⚠ 越えてはならない境界

```text
⚠ 入る人の経路に 1 行も足さない          ⚠ ノック、扉、待機 socket、通話
⚠ Google は サインインの往復にだけ現れる  ⚠ 通話中に外へ出ない
⚠ cookie と join token は purpose で分かれる ⚠ 両方向で検査する(0029)
⚠ 段階 1 では 保存しない                 ⚠ D1 を入れるのは別の ADR
⚠ 門を通らない作成経路を 1 つも作らない   ⚠ 検査で押さえる
⚠ メールアドレスをログに出さない          ⚠ security.md § 2
```

## ⚠ しないと決めた主張

- ⚠ **「これでサービスになった」とは言わない。** ⚠ **門が配って回る鍵でなくなった、までである。**
- ⚠ **「Google が安全だから安全」とは言わない。** ⚠ **我々が受け取るのは、⚠ 検証した ID token から
  取り出した 1 つのメールアドレスだけである。**
- ⚠ **段階 2 の費用について、⚠ いまは何も言わない。** ⚠ **測っていない。**
