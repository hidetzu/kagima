⚠ **so 候補として Worker + Durable Objects を調べた。**
⚠ **調べ方は読むことではなく、⚠ 動かすことにした。**

### ⚠ 実際に動かして測ったこと(2026-09-05)

⚠ **`wrangler dev --local` を使い、⚠ アカウント無し・課金無しで、⚠ 捨てるコードとして書いた。**
⚠ **kagima のリポジトリには 1 ファイルも入れていない。**

## ⚠ 移ると失うもの

### ⚠ 1. ビルドステップが無い、という性質

⚠ **[`0002`](0002-serve-web-and-signaling-from-one-typescript-process.md) は
「1 つの Node プロセス」を決めており、⚠ ビルドステップが無いことがその中身である。**
⚠ **Node が `.ts` をそのまま実行し、⚠ `stripTypeScriptTypes` がブラウザにも `.ts` を配っている。**

⚠ **Worker では両方が消える。** ⚠ **wrangler は自前の bundler を持ち、⚠ 設定なしで `.ts` を
束ねた** — ⚠ **便利であり、⚠ そして `CLAUDE.md` § 3 が「ADR なしに入れない」と言う
「第二のビルドシステム」そのものである。**

⚠ **ブラウザに配る `src/client/*.ts` も変換が要る。** ⚠ **いま「配るだけ」で済んでいるものが、
⚠ 「作ってから配る」になる。**

### ⚠ 2. 比較が同期でなくなる

⚠ **`constantTimeEqual` は同期である**(`src/token/join-token.ts`)。
⚠ **Workers の `crypto.subtle` は非同期なので、⚠ 比較が `Promise` を返すようになる。**

⚠ **so `attemptJoin` とその呼び出し側が全部 async になる。**
⚠ **これは security 上の要の経路であり、⚠ 「ついでに書き換える」場所ではない**
([`../../.claude/rules/security.md`](../../.claude/rules/security.md) § 1)。

### ⚠ 3. 検証のいくつかが、いまの形では走らなくなる

⚠ **`npm run e2e` はサーバを同一プロセスで起動し、⚠ `stopAnswering()` で内側から止めている。**
⚠ **ケース `signalling-drops` はそれに依存している。**
⚠ **Worker ではプロセスの内側に手が入らない。** ⚠ **別の作り方が要る。**

⚠ **一方で:**
⚠ **`src/` の 16 ファイルは `node:` を 1 つも import していない** — ⚠ **hub、rate-limit、store、
join、messages、status、diagnostics、passphrase の正規化と語彙。**
⚠ **fast tier はそのまま効く。** ⚠ **external tier(ブラウザ間)は何も変わらない。**

### ⚠ 4. 継続的な running cost が発生しうる

⚠⚠ **ここが決定的であり、⚠ そして ここが唯一「測っていない」ところである。**

⚠ **Durable Objects の課金条件を、⚠ この調査では確かめていない。**
⚠ **ローカル実行に課金は無いが、⚠ それは本番の話ではない。**
⚠ **数字を書かない** — ⚠ **調べていないからである**
([`../../.claude/rules/evidence.md`](../../.claude/rules/evidence.md))。

⚠ **「継続的な running cost が発生する構成」は Owner 判断である**
([`../PRODUCT.md`](../PRODUCT.md) § 6)。
⚠ **so これは技術判断ではない。** ⚠ **金額を確かめるまで、⚠ AI は採用を提案できない。**

## ⚠ しないと決めた主張

- ⚠ **「Worker では動かない」とは言わない。** ⚠ **動いた。**
- ⚠ **「Worker のほうが安い / 高い」とは言わない。** ⚠ **測っていない。**
- ⚠ **「Node 版のほうが単純である」とも言わない。**
  ⚠ **単純なのは今の**ビルド**であって、⚠ 運用は家庭内 PC を動かし続けることである。**
- ⚠ **この草案は移行計画ではない。** ⚠ **移ると決めたら、⚠ 何をどの順で置き換えるかは別に書く。**

## ⚠ 何が分かれば決められるか

```text
1  Durable Objects の課金条件 (⚠ Owner が確認する。⚠ 数字は測るまで書かない)
```
