# 0024. ルームを作るところに、⚠ 一時的な門を置く

- 状態: **決定**(⚠ **期限つき**。⚠ 終わり方は下記)
- 日付: 2026-09-06
- 決めた人: **Owner**

## 文脈

⚠ **`POST /api/rooms` は誰でも叩ける。** ⚠ **実測(2026-09-06、⚠ `wrangler dev --local`):**

```text
⚠ 20 回叩いて 20 個できた
⚠ 認証は 1 つも要らない
```

⚠ **Node ではこれで困らなかった。** ⚠ **1 プロセスのメモリであり、⚠ 掃除が回り、⚠ プロセスが
終われば全部消えた**([`0005`](0005-keep-room-state-in-process-memory-only.md))。

⚠⚠ **Cloudflare では 3 つ変わる:**

| | |
|---|---|
| ⚠ **1 ルーム = 1 Durable Object** | ⚠ **作られるたびに object が 1 つ増える**([`0022`](0022-start-on-cloudflares-free-tier-with-one-durable-object-per-room.md)) |
| ⚠ **書く** | ⚠ **storage の行が 1 つ増える**([`0023`](0023-write-the-minimum-so-a-room-outlives-its-sockets.md)) |
| ⚠⚠ **掃除が無い** | ⚠⚠ **Node の sweeper に当たるものが Durable Object 側に無い。** ⚠ **誰も消さない** |

⚠ **そして Free の境界は 28.21 room-hours/day である**
([`0022`](0022-start-on-cloudflares-free-tier-with-one-durable-object-per-room.md))。
⚠ **上限を超えると、⚠ 課金ではなく その種類の operation が失敗する** — ⚠⚠ **すなわち
サービスが応じなくなる。**

## 決定

⚠ **ルームを作るところに、⚠ 共有の合言葉による門を置く。**

⚠ **`GET /` と `POST /api/rooms` の 2 つだけ。** ⚠ **他は 1 つも変えない。**

### ⚠⚠ ゲストは 1 つも要らない

```text
⚠ /r/{roomId}                       ⚠ 門の外
⚠ POST /api/rooms/{id}/knock        ⚠ 門の外
⚠ GET  /api/rooms/{id}/knock/{id}   ⚠ 門の外
⚠ WebSocket .../signal              ⚠ 門の外(⚠ token が門である)
```

⚠⚠ **これが要点である。** ⚠ **門はルームを 作る 人のためのものであって、⚠ 入る 人のもの
ではない。** ⚠ **招かれた人に合言葉を渡すことになれば、⚠
[`0017`](0017-let-the-host-decide-who-comes-in-instead-of-a-passphrase.md) が捨てたものを
裏口から戻すことになる。**

### ⚠ 使うのは HTTP Basic

⚠ **ブラウザが訊いてくれる。** ⚠ **kagima 側に画面が 1 つも増えない。**
⚠ **`docs/PRODUCT.md` § 3 の流れに手を入れない、⚠ という一点で選んだ。**

⚠ **合言葉ではない** — ⚠ **[`0017`](0017-let-the-host-decide-who-comes-in-instead-of-a-passphrase.md)
が捨てた「合言葉」は 入口 のものであり、⚠ これは 運用上の門 である。**
⚠ **`CLAUDE.md` § 4: ⚠ 「passphrase」は人が口で言うもののための語である。** ⚠ **この門を
そう呼ばない。**

## ⚠ 越えてはならない境界

```text
⚠⚠ ゲストの経路に 1 つも足さない
⚠ 定数時間で比べる                  ⚠ security.md § 1
⚠ ログに出さない                    ⚠ security.md § 2
⚠ 既定値を作らない                  ⚠ 設定されていなければ 門は無い、と言う
⚠ 断り方を 1 つにする               ⚠ 何が違ったかを言わない
⚠ HTTPS の上でだけ意味を持つ         ⚠ そう書く
```

### ⚠ 設定されていないとき

⚠ **門は無い。** ⚠ **`wrangler dev --local` も、⚠ Node も、⚠ いままでどおり動く。**
⚠⚠ **黙って通すのではなく、⚠ 「門は設定されていない」と 起動時に言う。**
⚠ **`security.md` § 6 の「既定値を作らない」と同じ形である。**

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| **何もしない** | ⚠⚠ **20 回叩けば 20 個できる。** ⚠ **Free の上限に届けば サービスが応じなくなる** |
| **Cloudflare Access** | ⚠ **Cloudflare のアカウントと設定に依る。** ⚠ **`wrangler dev --local` で検査できなくなる** |
| **Turnstile** | ⚠ **人かどうかを見る仕組みであり、⚠ 「この人たちだけ」ではない。** ⚠ **kagima#56 で見たとおり、⚠ 第三者の可用性に依る** |
| **ルーム作成にレート制限** | ⚠ **上限を遅らせるだけで、⚠ 誰でも作れることは変わらない。** ⚠ **併用はできる** |
| **入口の合言葉を戻す** | ⚠⚠ **[`0017`](0017-let-the-host-decide-who-comes-in-instead-of-a-passphrase.md) を覆すことになる。** ⚠ **これは 入口 ではなく 運用上の門 である** |

## ⚠⚠ 終わり方 — ⚠ 始める前に書く

⚠ **これは 製品の一部ではない。** ⚠ **`docs/PRODUCT.md` にこの門は 書かない。**

⚠ **終わらせる条件:**

```text
⚠ 誰でも作れてよい、と Owner が決めたとき
⚠ もしくは、⚠ ルームを作ることに別の上限が入り、⚠ Free の境界に届かなくなったとき
```

⚠ **終わらせる PR は、⚠ 消えたものの一覧を ADR に置き、⚠ `docs-check` が不在を押さえる**
([`0011`](0011-turn-on-a-field-test-mode-that-costs-two-promises-on-purpose.md) と
[`0014`](0014-retire-the-field-test-mode-now-that-kagima-16-is-closed.md) と同じ形)。

## ⚠ しないと決めた主張

- ⚠ **「これで安全になる」とは言わない。** ⚠ **言えるのは「合言葉を知らない人はルームを
  作れない」までである。**
- ⚠ **「濫用を防ぐ」とも言わない。** ⚠ **合言葉を知っている人が何個作るかには、⚠ 何の上限も
  無い。** ⚠ **それは別の問題である。**
- ⚠⚠ **掃除が無いことは、⚠ この門では直らない**(下記)。

## ⚠ 一緒に見つかったこと — ⚠ 掃除が無い

⚠ **Node には sweeper が在る**(`src/node-server.ts`)。⚠ **Durable Object 側には無い。**
⚠ **so 期限が切れたルームの storage は、⚠ 誰も読まなければ 残り続ける。**

⚠ **`0023` は「読むときに期限を見る」と決めた。** ⚠ **それは 届かなくする ことであって、
⚠ 消す ことではない。**

⚠⚠ **この ADR では直さない。** ⚠ **門とは別の問題であり、⚠ 別に切る。**
