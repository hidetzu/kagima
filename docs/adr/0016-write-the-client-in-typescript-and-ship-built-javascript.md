# 0016. クライアントは TypeScript で書き、⚠ ブラウザへはビルドした JavaScript を配る

- 状態: **決定**
- 日付: 2026-09-05
- 決めた人: **Owner**
- 対象: ⚠ **[`0015`](0015-put-the-service-on-cloudflare-after-three-things-are-settled.md) の移植時**。
- ⚠ **実施: 2026-09-06。** ⚠ **Node 版もビルド成果物を配るようになった** — ⚠ **移植時に切り替えると、
  ⚠「動いていた形」と「動かす形」が同時に変わる。** ⚠ **先に入れて、いまの検査で押さえた。**
- 片付ける課題: [kagima#48](https://github.com/hidetzu/kagima/issues/48)

## 文脈

⚠ **いま、ブラウザに届くものはソースそのものである。**

```text
ディスクの .ts → ⚠ Node の stripTypeScriptTypes → ⚠ 型を空白に置き換えた JS をその場で配る
```

⚠ **実測(2026-09-05)** — ⚠ `/status/status.ts` を叩くと:

| | ソース | ⚠ ブラウザに届くもの |
|---|---|---|
| `content-type` | — | ⚠ `text/javascript; charset=utf-8` |
| `export type Ending` | 1 | ⚠ **0** |
| `: string` | 3 | ⚠ **0** |

⚠ **so「拡張子が `.ts` だから動かない」ではない。** ⚠ **ブラウザは URL の拡張子を見ない。**
⚠ **見るのは `content-type` と中身である。** ⚠ **URL は `.ts` のまま、⚠ 中身は JS である。**

⚠ **Worker には `node:module` が無い。** ⚠ **so この変換の置き場所が消える。**

## 決定

⚠ **クライアントは TypeScript で書き続ける。** ⚠ **ブラウザへは、ビルドした JavaScript を配る。**

⚠ **型の恩恵は 1 つも失わない。** ⚠ **`npm run check` の `types-client` はそのまま効く。**
⚠ **失うのは「ソースと、ブラウザが実行するものが同一」という性質だけである。**

## ⚠ 決め手 — ビルドはどのみち来る

⚠ **`CLAUDE.md` § 3 は「第二のビルドシステム」を ADR 無しに入れることを禁じている。**
⚠ **そして [`0015`](0015-put-the-service-on-cloudflare-after-three-things-are-settled.md) を採る時点で、
⚠ wrangler が Worker 本体を必ず束ねる。** ⚠ **選択の余地は無い。**

⚠ **so 「ビルドが無い」という利点は、⚠ クライアントの書き方に関わらず既に失われている。**
⚠ **その状態でクライアントだけ手書き JS にしても、⚠ 何も取り戻せず、⚠ 型検査だけ失う。**

## ⚠ 越えてはならない境界

⚠ **[`0002`](0002-serve-web-and-signaling-from-one-typescript-process.md) が守っていた本当の価値は
「ビルドが無い」ではなく、⚠ 「ソースと配信物が同一」だった。**
⚠ **so それが分かれる以上、⚠ 分かれたことを検査が知っていなければならない。**

```text
⚠ 最終ゲートは、ソースではなくビルド成果物に対して走る
⚠ ソースを読む検査は「入力についての主張」であり、⚠ 「出力についての主張」ではない
```

⚠ **kagima の検査には、⚠ ソースを読むものが既にいくつもある** — ⚠ **ページが正規化規則を
import しているか、⚠ listener が `createCall` より前にあるか、⚠ `track` で connected を
決めていないか。** ⚠ **これらは移植後も「入力についての主張」であり続ける。**

⚠ **出力についての主張を持つのは、⚠ 実ブラウザを動かす e2e だけである。**
⚠ **その区別を意識せずに移ると、⚠ 「検査は緑なのに、配られた物は違う」が起こりうる。**

⚠ **so e2e は `wrangler dev` を相手にする** — ⚠ **それはそのままビルド成果物を叩く形になる。**

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| ⚠ **Worker の中でリクエストごとに変換する** | ⚠ **DO の duration に直接効く**([`0015`](0015-put-the-service-on-cloudflare-after-three-things-are-settled.md) で測り始めた量である)。⚠ **変換器を Worker のバンドルに持ち込む必要もある。** ⚠ **コストを払って ① より悪い** |
| ⚠ **クライアントを最初から `.js` で書く** | ⚠ **ビルドは Worker 側で来るので、⚠ 「ビルドが無い」利点は取り戻せない。** ⚠ **`types-client` だけ失う** |
| **`.ts` をそのまま配る** | ⚠ **ブラウザは TypeScript を実行できない。** ⚠ **いまも配っているのは型を除いた JS である** |
| ⚠ **ビルド成果物を git に入れる** | ⚠ **ソースと成果物が二重に存在し、⚠ 必ず片方が古くなる**(`CLAUDE.md` § 3) |

## ⚠ しないと決めた主張

- ⚠ **「ビルドステップが増えても複雑にならない」とは言わない。** ⚠ **複雑になる。**
  ⚠ **それでも選ぶのは、⚠ 避けられないからである。**
- ⚠ **「ソースを読む検査で出力を保証できる」とは言わない。**
  ⚠ **できない。** ⚠ **だから上の境界を書いた。**
- ⚠ **この ADR は移植計画ではない。** ⚠ **どのツールで、どの順で束ねるかは、⚠ 移植の PR で決める。**

## ⚠ [`0002`](0002-serve-web-and-signaling-from-one-typescript-process.md) との関係

⚠ **いまは置き換えない。** ⚠ **Node 版は動いており、⚠ ビルドステップは無いままである。**
⚠ **移植が完了した時点で、⚠ `0002` の「ビルドステップが無い」部分が置き換わる。**
⚠ **そのとき `0002` の状態を書き換える** — ⚠ **削除はしない。**


## ⚠ 入れたときに分かったこと(2026-09-06)

⚠ **新しい依存は 1 つも入っていない。**
⚠ **変換は同じ `stripTypeScriptTypes` であり、⚠ リクエスト時からビルド時へ動いただけである。**
⚠ **バンドラは要らなかった** — ⚠ **ブラウザが ES modules を解決するので、⚠ 1 ファイルにまとめる
理由が無い。** ⚠ **`CLAUDE.md` § 3 の「第二のビルドシステム」には当たらない。**

⚠ **`scripts/build.ts` がやることは 2 つだけである:**

```text
型を落とす        ⚠ Node 自身の stripTypeScriptTypes
"./x.ts" を "./x.js" に書き換える   ⚠ 相対指定だけ。⚠ 他に触るものが無い
```

### ⚠ 払った代償と、その壁

⚠ **ソースと、ブラウザが実行するものが、2 つのファイルになった。** ⚠ **2 つは食い違いうる。**

| 食い違い | ⚠ 何が止めるか |
|---|---|
| ⚠ **dist/ が古い** | ⚠ **両方のゲートが走る前にビルドする**(`scripts/e2e.ts`, `scripts/external.ts`)。⚠ **呼ぶ側に覚えさせない** |
| ⚠ **ページが、ビルドが書かない名前を import する** | ⚠ **`test/build.test.ts`。** ⚠ **HTML の中の import は `tsc` に見えない** |
| ⚠ **どれかの経路が `src/` を読みに戻る** | ⚠ **`test/build.test.ts`。** ⚠ **Worker では動かず、⚠ Worker でしか見つからない** |
| ⚠ **ビルドせずに起動する** | ⚠ **`startServer` が起動時に落ちる。** ⚠ **1 リクエストの stack trace ではなく、⚠ やるべきことを言う** |

⚠ **実測(2026-09-06)** — ⚠ **`dist/` を正しく焼いたまま、⚠ ソースだけを壊し、⚠ ゲートから
「先にビルドする」行を外すと、⚠ 壊れたソースのまま `1 of 1 cases passed` になった。**
⚠ **その行が壁である。**

⚠ **`docs/adr/0002` が避けたかったものは、⚠ 消えてはいない。** ⚠ **見張りに変わっただけである。**
