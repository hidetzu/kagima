# 0017. 入口を合言葉から Host の招待に変える

- 状態: **決定**
- 日付: 2026-09-06
- 決めた人: **Owner**
- ⚠ **[`../PRODUCT.md`](../PRODUCT.md) § 1 の概念を変えた決定である。** ⚠ **最も上位の変更である。**
- ⚠ **まだ実装していない。** ⚠ **コードは合言葉のままである。**

## 決定

```text
前  合言葉で、ひとときだけ開くプライベート空間
今  ⚠ 招待した人にだけ、ひととき開くプライベート空間
```

⚠ **入口は「秘密を知っているか」ではなく、⚠ 「Host が招いたか」になる。**
⚠ **Guest は URL を開いて名乗り、⚠ Host が入れると決めるまで待つ。**

## ⚠ なぜ変えたか — ⚠ 3 つとも実測から来ている

### ⚠ 1. 合言葉の入力が、⚠ 実機で重かった

⚠ **[kagima#40](https://github.com/hidetzu/kagima/issues/40) の実測:**
⚠ **「スマホでの合言葉入力が結構大変」**(Owner の言葉)。

```text
4 語 = 28 bit / 平均 27.7 打鍵
⚠ 語は romaji なので、⚠ 日本語 IME のままだと合言葉が空になる
⚠ そして拒否は 1 種類しか返さないので、⚠ 利用者には何も分からない
```

⚠ **手当て**(`inputmode` と事前の注意書き)**は入れた** — ⚠ **打鍵は減っていない。**
⚠ **強度を上げるなら 5 語で 34.9 打鍵、⚠ さらに 26% 増える。**

### ⚠ 2. レート制限が、⚠ 移植の前で行き止まりになった

⚠ **[kagima#56](https://github.com/hidetzu/kagima/issues/56)。**
⚠ **`ROOM_LIMIT` は hard cap ではない**(⚠ 実測: source 85 本で 101 回通る)。
⚠ **so 分散した推測に対する上限は「source 数 × 制限」であり、⚠ 時間にも上限が無かった。**

⚠ **三案とも約束か費用に触れた:**

```text
source 単位 DO   ⚠ 「誰が、どのルームに入ろうとして失敗したか」を storage に書く
hard cap         ⚠ 攻撃者が本物の Guest を締め出せる
challenge        ⚠ 第三者スクリプト。⚠ そして challenge の有無が部屋の存在を漏らす
```

⚠⚠ **入口を変えると、⚠ この連鎖が始まらない。** ⚠ **推測される秘密が無いからである。**
⚠ **問題を解いたのではなく、⚠ 問題が発生する前提を外した。**

### ⚠ 3. Host は、⚠ どのみちその場に居た

⚠ **実測**([kagima#52](https://github.com/hidetzu/kagima/pull/52)):
⚠ **Host はルームを作った直後に signaling socket を開き、⚠ URL を配るあいだ開いたままにする。**

⚠ **so 「Host が招く」は新しい負担ではない。** ⚠ **既にそこに居た。**

## ⚠ 実験で確かめたこと

⚠ **ノックと承認だけの捨てるコードを作り、⚠ 実機で回した**(⚠ 本番には入れていない)。

| | ⚠ 観測 |
|---|---|
| ⚠ **Host がノックに気づくまで** | ⚠ **24 秒**(⚠ 1 回、⚠ 来ると知っていた Host) |
| ⚠ **待ち時間は許容できるか** | ⚠ **できる。** ⚠ **5 分程度でよい**(Owner 判断) |
| ノック 50 連打 | ⚠ **Host の画面に並ぶのは 5 件。** ⚠ **上限は外から見えない** |
| ⚠ **存在しないルームへのノック** | ⚠ **Host が応じていない部屋と同じ振る舞いにできた** |

## ⚠ 越えてはならない境界

```text
⚠ 存在しないルームと、Host が応じていない部屋を、外から区別できないようにする
   ⚠ 合言葉方式が守っていた性質であり、⚠ 入口が変わっても要る
⚠ 誰がノックしたかを記録に残さない  ⚠ 入れた人も、断った人も
⚠ 同時に待てるノックの数に上限を置く  ⚠ ただし上限に達したことを外に見せない
⚠ Host が居ないことと、断られたことを、同じ言葉で言わない
```

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| ⚠ **合言葉を 5 語にする** | ⚠ **打鍵が 26% 増える。** ⚠ **入口の摩擦は既に実測された問題である** |
| ⚠ **数字コードにする** | ⚠ **打鍵は 1/3 になる**(⚠ 9 桁で 28 bit)。⚠ **しかしレート制限の連鎖は残る** |
| **QR** | ⚠ **同じ場所に居るときにしか効かない。** ⚠ **画像で送れば URL と秘密が同じ経路に乗る** |
| ⚠ **absolute maximum lifetime を入れる** | ⚠ **攻撃窓は有限になるが、⚠ 長い通話が切られる**([`0010`](0010-a-room-lives-while-somebody-is-in-it-and-not-longer.md))。⚠ **入口を変えれば要らない** |

## ⚠ しないと決めた主張

- ⚠ **「これで安全になった」とは言わない。**
  ⚠ **壁の種類が変わっただけである** — ⚠ **推測から、⚠ 人の判断へ。**
  ⚠ **Host が誤って招き入れる余地は新しく生まれた。**
- ⚠ **「嫌がらせのノックは問題にならない」とも言わない。**
  ⚠ **URL が漏れる頻度を測っていない。**
- ⚠ **24 秒は 1 回の観測である。** ⚠ **平均でも最悪でもない。**
