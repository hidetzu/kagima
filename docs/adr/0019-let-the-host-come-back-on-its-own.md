# 0019. Host は自分で戻る。⚠ 戻れなかったときだけ、そう言う

- 状態: **決定**
- 日付: 2026-09-06
- 決めた人: **Owner**
- 片付ける課題: [kagima#70](https://github.com/hidetzu/kagima/issues/70)

## 文脈

⚠ **[`0017`](0017-let-the-host-decide-who-comes-in-instead-of-a-passphrase.md) は Host の承認を
入口そのものにし、⚠ [`0018`](0018-give-the-host-a-short-lived-role-inside-one-room.md) は
ノックが届く先を Host だけに絞った。**

⚠⚠ **その Host が、⚠ socket が切れたら戻れなかった。**

⚠ **実測(2026-09-06、`src/` を無改変で走らせた):**

```text
⚠ Host の socket を閉じた。⚠ 部屋の人数: 0
⚠ 部屋はまだ在るか: true
⚠ ノックの答え: 200 { knockId: … }
⚠⚠ Host が受け取った行: 0 本
⚠⚠ ノックした人が見るもの: waiting
```

⚠ **ノックした人に「Host が居ない」と見えないのは仕様である**([`0017`](0017-let-the-host-decide-who-comes-in-instead-of-a-passphrase.md))。
⚠ **守られている。** ⚠⚠ **問題は Host にも見えないことである。**

⚠ **ノック自体は失われていない。** ⚠ **失われたのは 通知 だけである** —
⚠ **`knocks` はサーバのメモリに持っており、⚠ その人はまだそこに立っている。**

⚠ **`0018` はこの穴を作っていない。** ⚠ **`0018` は、元から在った穴を 見えるようにした。**

## 決定

⚠ **Host のページは、⚠ 自分で繋ぎ直す。** ⚠ **上限まで試し、⚠ 戻れなかったときだけ そう言う。**

```text
socket が切れた   → ⚠ 黙って繋ぎ直す。⚠ 画面は変わらない
繋ぎ直せた        → ⚠ サーバが「いまドアに居る人」を渡す。⚠ 留守中のノックが出る
上限まで届かない  → ⚠ ここで初めて detached の文言(0010)
```

⚠ **繋ぎ直しには、⚠ 毎回 `hostKey` を短命な host token に交換し直す**
([`0018`](0018-give-the-host-a-short-lived-role-inside-one-room.md))。
⚠ **切れる前に持っていた token は、⚠ まさに もう使えないものである。**

### ⚠⚠ 繋ぎ直しているあいだ、⚠ 何も出さない

⚠ **Owner の決定(2026-09-06)。**

⚠ **根拠: ⚠ 一瞬の切断で「つながりが切れました」を出すと、⚠ 壊れていない通話について
壊れたと伝えることになる**(`CLAUDE.md` § 4-1)。
⚠ **メディアはブラウザ間を直接流れており、⚠ signalling が切れても止まっていない**
([`0001`](0001-keep-media-peer-to-peer-and-off-our-servers.md)、
[`0010`](0010-a-room-lives-while-somebody-is-in-it-and-not-longer.md))。

⚠ **代償: ⚠ 本当に繋がらないとき、⚠ 予算のあいだ 利用者は何も知らされない。**
⚠ **その予算は 選んだ値であって、測った値ではない**(下記)。

## ⚠ 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| **ボタンを出して促す** | ⚠⚠ **締め出しが起きるのは「URL を貼りに行っているあいだ」であり、⚠ そこは そもそも画面を見ていない時間である。** ⚠ **押せないボタンは無いのと同じ** |
| **切れたら即 `detached` を出し、⚠ 戻ったら消す** | ⚠ **一瞬の切断で毎回 画面が動く。** ⚠ **壊れていないものを壊れたと言う** |
| **通知を配り直さず、⚠ 繋ぎ直すだけ** | ⚠ **留守中のノックは 通知 が消えている。** ⚠ **繋がっても、⚠ 誰が来たか分からない** |
| **際限なく繋ぎ直す** | ⚠ **こちらへの攻撃になりうるし、⚠ 相手のブラウザの電池でもある** |
| **Guest 側も同時に** | ⚠ **Guest は token が切れていると ノックからやり直しになり、⚠ Host の承認をもう一度求める。** ⚠ **別の判断が混ざる** — ⚠ **切り分けた** |

## ⚠ 越えてはならない境界

```text
繋ぎ直しでトラックを止めない          ⚠ 0010。⚠ 通話は我々を必要としていない
答えである close は繰り返さない        ⚠ 4001 / 4002 / 4003 / 4005 / 1000
  ⚠ 4004(沈黙)は ここに入れない     ⚠ それこそ戻るべきものである (kagima#62)
再試行に上限を置く                     ⚠ 上限は「遅延の一覧の長さ」であり、他に隠れ場所を作らない
ドアの列は role=host にだけ渡す        ⚠ 0018 をここで壊さない
列に token を入れない                  ⚠ security.md § 4。⚠ Host に使い道が無い
ノックした側の振る舞いを 1 ビットも変えない  ⚠ 0017。⚠ Host が戻ったことが外から見えない
```

## ⚠ しないと決めた主張

- ⚠⚠ **再試行の遅延は 選んだ値であって、⚠ 測った値ではない**
  ([`../../.claude/rules/evidence.md`](../../.claude/rules/evidence.md))。
  ⚠ **「アプリを切り替えて URL を貼るのに実際どれだけかかるか」は誰も測っていない。**
  ⚠ **[kagima#62](https://github.com/hidetzu/kagima/issues/62) の実機計測が出たら、⚠ 見直す。**
  ⚠ **それまでは、⚠ 選んだ値だと書いておく。**
- ⚠ **「Host は必ず戻れる」とは言わない。** ⚠ **言えるのは「上限まで試す」までである。**
- ⚠ **「留守中のノックを取りこぼさない」とも言わない。**
  ⚠ **言えるのは「`knocks` に残っているものは渡す」までである。**
  ⚠ **待つのをやめた人は、⚠ もうそこに居ない。**

## 影響

- ⚠ **`docs/adr/0010` の 3 つの終わり方は変わらない。** ⚠ **`detached` が出る 条件 が変わる** —
  ⚠ **socket が切れた瞬間から、⚠ 戻れなかったときへ。**
- ⚠ **`e2e` の `signalling-drops` は、⚠ 予算より長く待つようになった。**
  ⚠ **予算を検査に合わせて縮めていない**([`../../.claude/rules/verification.md`](../../.claude/rules/verification.md))。

  型検査する。** ⚠ **`tsconfig.e2e.json` 側に置いた** — ⚠ **どの lib で確かめるかは、⚠ ファイルの
  置き場所ではなく 何に触るか で決まる**(⚠ `types-client` が在るのと同じ理由)。
