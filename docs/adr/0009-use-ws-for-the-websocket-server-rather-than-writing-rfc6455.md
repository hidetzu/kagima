# 0009. WebSocket サーバは `ws` を使い、RFC 6455 を自分で書かない

- 状態: **決定**
- 日付: 2026-09-04

## 決定

⚠ **WebSocket サーバとして `ws` を使う。** ⚠ **RFC 6455 のハンドシェイクとフレーミングを
自分で書かない。**

⚠ **これは kagima にとって最初の実行時依存である。**
⚠ **`CLAUDE.md` § 3 が「ADR なしに入れない」と言っているものに当たるので、これを書いている。**

## 文脈 — ⚠ 測ってから決めた

⚠ **Node にサーバ側の WebSocket は無い。** ⚠ **推測ではなく、実際に走らせて確認した:**

```
node -e "typeof WebSocket"        function   ⚠ ただしクライアント側だけ
node -e "typeof WebSocketServer"  undefined
```

⚠ **`node:http` の `upgrade` イベントは取れる。**
⚠ **つまり「自分で書ける」ことは確かである。** ⚠ **問題は、書くべきかである。**

## ⚠ 自分で書くと何を引き受けることになるか

⚠ **フレーミングは、外から来た長さとオフセットを読む処理である。**

```text
2 バイト長 / 8 バイト長の拡張ペイロード長   ⚠ 外から来た数値
マスクキーと unmask                        ⚠ 外から来たバイト列
フラグメント化されたメッセージの再構成      ⚠ 外から来た継続フレーム
制御フレームの長さ制限                     ⚠ 破ると仕様違反
```

⚠ **`.claude/skills/change-review/SKILL.md` § 3 が名指ししている行そのものである:**

> untrusted input — ⚠ **A length or an offset that came from outside, used without checking it
> against what was actually read**

⚠ **kagima の入口は、我々が管理していない経路で URL を渡された相手が叩く。**
⚠ **その入口のパーサを自作して、それが v0.1.0 で最も検査の薄いコードになる、というのは
交換として悪い。**

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| **RFC 6455 を自分で書く** | ⚠ **外から来た長さとオフセットを扱うコードが増える。** ⚠ **それが最も攻撃面の広い場所になる。** ⚠ **依存を 0 に保つことより、そこを枯れた実装に任せるほうが価値が高い** |
| **WebSocket をやめて long polling / SSE にする** | ⚠ **ICE candidate は双方向に、低遅延で流れる必要がある。** ⚠ **SSE は片方向で、long polling は遅延を足す** |
| **フレームワークを入れる**(Socket.IO 等) | ⚠ **独自プロトコルと再接続とルーム管理が付いてくる。** ⚠ **必要なのは素の WebSocket である。** ⚠ **`CLAUDE.md` § 3 の「1 プロセスが必要とする以上のものを入れない」に反する** |
| **Deno / Bun に替える** | ⚠ **第 2 のランタイムである**([`0002`](0002-serve-web-and-signaling-from-one-typescript-process.md) に反する) |

## ⚠ 越えてはならない境界

```text
ws を使うのは WebSocket の運搬だけである
  ⚠ ルーム管理・認証・再接続の判断を ws に委ねない。⚠ それは我々のコードである
ws の上に第 2 のプロトコル層を積まない
実行時にネットワークへ出ていく依存は、これを含めて 1 つも足さない
  ⚠ ws は接続を受けるだけで、⚠ 自分からどこかへ出ていかない
依存を増やすときは、そのたびに ADR を書く
```

## ⚠ しないと契約したこと

- ⚠ **「依存が無いから安全である」とは言わない。** ⚠ **依存はある。**
  ⚠ **言えるのは「外から来た長さを読むコードを自分で書かないほうが安全だと判断した」までである。**
- ⚠ **`ws` が安全であるとも言わない。** ⚠ **我々は監査していない。**
  ⚠ **広く使われていることは、正しいことの証明ではない**
  ([`../../.claude/rules/evidence.md`](../../.claude/rules/evidence.md))。
  ⚠ **言えるのは「我々が今日書くものより枯れている」までである。**

## 影響

- ⚠ **`npm ci` が依存を落とすようになる。** ⚠ **CI の時間が伸びる**(すでに大半が `npm ci` である)。
- ⚠ **供給網が 1 本増えた。** ⚠ **`package-lock.json` が、何を実際に入れたかの記録である。**
- ⚠ **`ws` は接続を受けるだけで、自分からネットワークへ出ていかない。**
  ⚠ **`CLAUDE.md` § 3 の「実行時にネットワークへ出ていく依存」には当たらない。**
