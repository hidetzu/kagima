# 0025. ルームは、⚠ 自分で自分を手放す

- 状態: **決定**
- 日付: 2026-09-06
- 対象: ⚠ [`0023`](0023-write-the-minimum-so-a-room-outlives-its-sockets.md) が作った義務

## 文脈

⚠ **[`0023`](0023-write-the-minimum-so-a-room-outlives-its-sockets.md) で書くようになった。**
⚠ **そこにこう書いた** — ⚠ **「書いたものは、⚠ 誰かが消さねばならない。⚠ プロセスが終われば
消える、はもう無い」。**

⚠⚠ **消す経路が 1 つ足りなかった。**

| いつ | ⚠ 誰が消すか |
|---|---|
| ⚠ Host が閉じた | ⚠ **在った**(`src/room-object.ts`) |
| ⚠ **期限が切れた** | ⚠⚠ **誰も居なかった** |

⚠ **Node には掃除が在る**(`src/node-server.ts` の sweeper)。
⚠ **Durable Object には、⚠ それを回すプロセスが無い。**

⚠ **so 作られたまま誰も読まないルームの storage は、⚠ 残り続けていた。**
⚠ **実測(2026-09-06): ⚠ `POST /api/rooms` を 20 回叩けば 20 個できる**
([`0024`](0024-put-a-temporary-gate-in-front-of-making-a-room.md))。

## 決定

⚠ **ルームが、⚠ いつ終わるかを 自分で覚える。**

```text
⚠ 書くたびに alarm を lastSeenAt + ROOM_IDLE_MS に張る
⚠ 鳴ったら:
    ⚠ もう無い     → ⚠ alarm を外して終わり
    ⚠ まだ生きている → ⚠ 張り直す(⚠ 心拍が lastSeenAt を動かした後である)
    ⚠ 終わっている   → ⚠ socket を閉じ、⚠ store から落とし、⚠ storage を消す
```

⚠ **順序は Node の sweeper と同じである** — ⚠ **socket が先。**
⚠ **さもないと、⚠ もう無いルームを掴んだままの人が残る。**

## ⚠ [`0010`](0010-a-room-lives-while-somebody-is-in-it-and-not-longer.md) は変わらない

⚠ **`0010` は「期限切れのルームは、⚠ 存在しなかったルームと同じ応答を返す。⚠ 回収を待たない」
と決めた。** ⚠ **それは いまも 読むときの期限判定が担っている**(`store.get`)。

⚠⚠ **この ADR は 別の半分である** — ⚠ **誰も届かないものを 持ち続けない。**
⚠ **掃除の周期に「届くかどうか」を依存させてはいない。**

## ⚠ 早く鳴ることは、⚠ 間違いではない

⚠ **心拍は 20 秒ごとに `lastSeenAt` を動かし、⚠ alarm もそのたびに動く。**
⚠ **それでも、⚠ 動かす前に鳴る順序はありうる。**

⚠ **so 鳴ったときに もう一度 見る。** ⚠ **早ければ張り直す。**
⚠⚠ **消さない。** ⚠ **生きているルームを消せば、⚠ 誰も終わらせていない通話を我々が終わらせる**
([`0010`](0010-a-room-lives-while-somebody-is-in-it-and-not-longer.md))。

## 却下した案

| 案 | ⚠ 却下の理由 |
|---|---|
| **消さない** | ⚠⚠ **`0023` が作った義務を果たさない。** ⚠ **Free の storage は 5 GB、⚠ 行は 100,000/day である**([`0022`](0022-start-on-cloudflares-free-tier-with-one-durable-object-per-room.md)) |
| **別の掃除役を置く**(⚠ cron な Worker など) | ⚠ **部屋をまたぐものが必要になる。** ⚠ **[`0022`](0022-start-on-cloudflares-free-tier-with-one-durable-object-per-room.md) の「1 ルーム = 1 DO」を崩す** |
| **読むときに消す** | ⚠ **誰も読まないルームが消えない。** ⚠ **それがいまの状態である** |
| **鳴ったら無条件に消す** | ⚠⚠ **早く鳴ったとき、⚠ 生きているルームを消す** |

## ⚠ しないと決めた主張

- ⚠ **「20 分で必ず消える」とは言わない。**
  ⚠ **alarm が本当に 20 分後に鳴ることは 測っていない** — ⚠ **`wrangler dev --local` で
  20 分待つ検査は、⚠ 誰も走らせない。**
  ⚠ **測ったのは「alarm を張れること」と、⚠ 「鳴らしたときに正しく振る舞うこと」までである。**
- ⚠ **「storage が空になる」とも言わない。**
  ⚠ **言えるのは「消す経路が在り、⚠ 検査がそれを見た」までである**
  ([`0005`](0005-keep-room-state-in-process-memory-only.md) の evidence の行)。

## 影響

- ⚠ **[`0023`](0023-write-the-minimum-so-a-room-outlives-its-sockets.md) の義務が果たされた。**
- ⚠ **[`0024`](0024-put-a-temporary-gate-in-front-of-making-a-room.md) の門は、⚠ 別のままである** —
  ⚠ **掃除は 溜まる速さ を下げない。** ⚠ **溜まったものが 出ていく ようにするだけである。**
